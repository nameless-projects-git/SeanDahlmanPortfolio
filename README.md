# Sean Dahlman — Geospatial Analyst Portfolio

Personal portfolio site showcasing GIS, remote sensing, GeoAI, and spatial programming work.

**[→ View Live Site](https://seanvdahlman.github.io/)**

## About

GIS professional with 6+ years of experience spanning municipal operations, environmental monitoring, and geospatial automation. Currently completing an MSc in GIS at Vrije Universiteit Amsterdam, with thesis research applying multi-modal deep learning to urban tree canopy detection.

## Selected Projects

- **GeoAI Urban Tree Canopy Detection** — Multi-modal U-Net pipeline fusing NAIP imagery with LiDAR for citywide tree detection (IoU 0.952, F1 0.975)
- **Prescribed Burn Digital Twin** — FlamMap fire behavior modeling validated against Sentinel-2 dNBR analysis
- **Predictive Invasive Weed Mapping** — Random Forest classification across 57 USFS Ranger Districts (AUC 0.987)
- **Sardinian Farmland Decline** — Multi-temporal Landsat NDVI/SAVI analysis (2007–2024)
- **Flood Impact Assessment** — Python raster analysis pipeline for Rockhampton, Queensland
- **Untitled Events** — Full-stack PWA with Leaflet maps, React, Node.js, and PostgreSQL

## Tech Stack

Built with vanilla HTML, Tailwind CSS (CDN), and Google Fonts. No build step required — served directly via GitHub Pages.
