GeoAI Urban Tree Canopy Detection

Multi-modal U-Net deep learning pipeline fusing NAIP 60cm imagery (RGB+NIR) with LiDAR-derived nDSM for citywide tree canopy detection across 227 km² of Boise, Idaho. Achieved test IoU of 0.952 and F1 of 0.975. Adding LiDAR height improved IoU by 30% over spectral-only methods.

Created physics-based training labels (NDVI + nDSM thresholds) validated against 34,499 field-surveyed trees at 90% detection rate. Delineated 261,262 individual tree crowns via marker-controlled watershed segmentation.
